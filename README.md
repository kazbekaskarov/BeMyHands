# Qolda

> «Будь моими руками» — десктоп-приложение для **macOS**, которое полностью заменяет мышь и клавиатуру.
> Управляй курсором движениями головы и печатай голосом. Локально, без облака.

Стек: **Electron** + **MediaPipe FaceLandmarker** (52 face-blendshapes) + **whisper.cpp** (Metal, large-v3) + **nut-js** (системный курсор/клавиатура).

Интерфейс на 🇷🇺 RU · 🇬🇧 EN · 🇰🇿 KZ · 🇹🇷 TR.

---

## Кому это нужно

- Людям с травмой, болезнью или временной потерей моторики — когда руки недоступны.
- Тем, кто хочет «пощупать» hands-free управление компьютером для исследований/прототипов.
- Программистам с RSI / туннельным синдромом — для разгрузки рук в течение дня.

После одноразовой настройки помощником приложение **запускается само** при включении Mac, само управляет курсором и голосом — без единого нажатия пальцами.

---

## Возможности кратко

- 🎯 **Трекинг лица** в реальном времени (MediaPipe Tasks Vision, GPU/WASM, ~30 fps).
- 🖱️ **Системный курсор** через nut-js — работает поверх любых приложений.
- 😉 **5 жестов лицом** → клики, drag, scroll.
- 🎙️ **3 движка голоса:** Local Whisper (offline) · Web Speech · OpenAI Whisper.
- 🗣️ **70+ голосовых команд** на 4 языках: курсор, редактор, запуск приложений, системные действия.
- 🔊 **Локальная диктовка** через whisper.cpp с непрерывным VAD.
- 🪟 **Always-on-top бар** со статусом + крестик-прицел в режиме точности.
- 🎯 **Hot-corners** — углы экрана как аварийные кнопки.
- 👤 **Use-mode** — окно настроек прячется, остаётся только тонкая полоса.
- 💾 **Авто-сохранение** всей конфигурации (калибровка, пороги, язык, чек-боксы) в `~/Library/Application Support`.

## Установка

```bash
git clone <repo> Qolda
cd Qolda
npm install

# Один раз: установить whisper.cpp и скачать модель (~3 ГБ для large-v3)
brew install whisper-cpp
npm run setup

npm start
```

> При первом запуске macOS попросит доступ к **камере** и **микрофону**. После — нужно вручную выдать **Accessibility** (см. ниже).

### Сменить модель Whisper

По умолчанию `large-v3` (топ по качеству, ~3 ГБ). Альтернативы — задать `WHISPER_MODEL` в `.env`:

| Модель           | Размер | На M2/M3        | Качество        |
|------------------|--------|-----------------|-----------------|
| `large-v3`       | 3.1 ГБ | ~1× реалтайма   | максимум        |
| `large-v3-turbo` | 1.6 ГБ | ~5× реалтайма   | очень высокое   |
| `medium`         | 1.5 ГБ | ~10× реалтайма  | хорошо          |
| `small`          | 488 МБ | ~20× реалтайма  | приемлемо       |

```bash
echo 'WHISPER_MODEL=large-v3-turbo' >> .env
npm run setup       # скачает выбранную модель
```

## Разрешения macOS (обязательно)

Чтобы Electron мог двигать курсор и нажимать клавиши **за пределами** окна, его нужно добавить в:

`System Settings → Privacy & Security → Accessibility`

В приложении в разделе **Разрешения** есть кнопки, открывающие нужные панели. После выдачи прав — **перезапустите приложение**.

При запуске через `npm start` в Accessibility надо добавить также `Terminal.app` (или `iTerm.app`). При сборке `.app` через `electron-builder` — само приложение.

## Использование

### 🔧 Разовая настройка (помощник, человек с руками)

1. Запустить `npm start`.
2. Сесть перед камерой как обычно сидит пользователь, дождаться зелёного «Готово».
3. Нажать **🎯 Калибровать** — это становится «центром».
4. Нажать **▶ Включить управление**.
5. В разделе **Курсор** подобрать чувствительность X/Y и сглаживание так, чтобы курсор уверенно доходил до углов экрана без перенапряжения шеи.
6. В разделе **Жесты лицом** проверить и подкрутить пороги по live-индикатору справа от каждой строки.
7. В разделе **Голос** включить **Local Whisper (offline)** + чек-бокс **Непрерывный режим**.
8. В разделе **Hands-free** включить нужные галки (см. ниже).
9. Нажать **Режим использования** — окно сворачивается. Все настройки сохранены, при следующем запуске всё сразу заработает.

### 👁️ Безрукое использование

Если включён **Автозапуск** в Hands-free, при старте приложения сразу:
- запускается курсор-трекинг;
- запускается голос в непрерывном режиме;
- остаётся только тонкая always-on-top полоса со статусом.

Для запуска вместе с macOS добавить приложение в **System Settings → General → Login Items** (или собрать `.app` через `electron-builder` и положить в `/Applications`).

## Жесты лицом

| Жест                            | Действие             | MediaPipe shape          |
|---------------------------------|----------------------|--------------------------|
| 👄 открыть рот                   | левый клик           | `jawOpen`                |
| 🤨 поднять брови                 | правый клик          | `browInnerUp`            |
| 😊 улыбнуться                    | двойной клик         | `mouthSmile L+R`         |
| 👁️ закрыть **левый** глаз       | зажать ЛКМ (drag)    | `eyeBlinkLeft`           |
| 👁️ закрыть **правый** глаз      | режим прокрутки      | `eyeBlinkRight`          |

В режиме **drag** держите глаз закрытым и двигайте головой — курсор тащит элемент. Открыли — отпустилось.

В режиме **scroll** наклоняйте голову вверх/вниз — страница скроллится. Скорость нелинейная: маленький наклон = медленно, сильный = быстро.

Каждый жест можно отключить чек-боксом и подстроить порог срабатывания индивидуально.

## Голосовые команды

Все команды распознаются перед печатью текста. Если фраза не подошла под команду — она уходит как текст в активное приложение. Есть **умное снятие префиксов** (см. ниже).

| Сказать                                    | Действие                                   |

| **«калибровка» / «центр» / «calibrate»**   | сбросить нейтральное положение головы (3-2-1) |
| **«клик» / «нажми»**                       | левый клик                                  |
| **«правый клик»**                          | правый клик                                 |
| **«двойной клик»**                         | двойной клик                                |
| **«вверх» / «вниз»**                       | прокрутка                                   |
| **«ввод» / «энтер»**                       | Enter                                       |

### Умное снятие префиксов

Можно говорить естественно — система снимает «вежливые» префиксы перед матчингом:

> «**Сделай** громче» → команда `громче` ✓
> «**Давай** открой ютуб» → команда `открой ютуб` ✓
> «**Пожалуйста**, сохрани» → команда `сохрани` ✓
> «**По**громче» → схлопывается до `громче` ✓

Снимаются: `сделай / сделать / делай / давай / можешь / можно / пожалуйста / плиз / немного / чуть / please / hey / let's / lütfen / hadi / жасашы …`

Если пользователь сказал ТОЛЬКО префикс («Сделай.») — текст НЕ печатается, помечается `[Сделай …]` в транскрипте. Это защищает браузер от паразитного пробела (который иначе скроллит страницу).

## Hot-corners (углы экрана)

Наведи курсор в угол на 1.2 сек:

| Угол               | Действие                                                                  |
|--------------------|---------------------------------------------------------------------------|
| ↖ левый верхний    | пауза / возобновить                                                       |
| ↗ правый верхний   | вернуть окно настроек                                                     |
| ↘ правый нижний    | 🛑 экстренная пауза (отпускает зажатую ЛКМ, выходит из drag/scroll)        |

Включается чек-боксом «Углы экрана» в Hands-free.

## Hands-free поведение (раздел в UI)

| Опция                       | Что делает                                                              |
|-----------------------------|--------------------------------------------------------------------------|
| Автозапуск при открытии     | сразу включает курсор + непрерывный голос                                |
| Авто-пауза без лица         | если 2 сек нет лица в кадре — управление приостанавливается              |
| Углы экрана                 | hot-corners включены                                                    |
| Голосовые команды           | парсер команд активен (без него всё уходит в `typeText`)                |

## Известные ограничения

- nut-js на Apple Silicon собирается из исходников; нужны Xcode Command Line Tools (`xcode-select --install`).
- Web Speech API в Electron использует Google endpoint и иногда недоступен — в этом случае используйте Local Whisper.
- При нескольких мониторах берётся `screen.getPrimaryDisplay()` — multi-display не реализован.
- Brightness работает через `key code 144/145` (System Events) — на некоторых внешних мониторах macOS не отдаёт управление.
- Continuous-режим Whisper может «слышать» разговоры на фоне — для созвонов скажите «**стоп**», по окончании «**слушай**».

## Диагностика

В DevTools-консоли (`Cmd+Option+I` в окне настроек) доступны:

```js
yonieDiag()                 // полная статистика трекинга, FPS, ошибок MediaPipe
[voice-cmd]                 // лог парсинга каждой голосовой команды:
                            //   text → after-stripper → matched name | no match
```

Если что-то пошло не так — сначала открывайте консоль и смотрите `[voice-cmd]`. Чаще всего проблема в том, что распознанный текст не такой, как ожидается.
