# BeMyHands

> «Будь моими руками» — десктоп-приложение для macOS, которое **полностью заменяет мышь и клавиатуру** для людей, которые не могут ими пользоваться. Управляй курсором движениями головы и печатай голосом.

Сделано на Electron + MediaPipe FaceLandmarker + whisper.cpp. Работает офлайн, не требует облака.

## Кому это нужно

- Людям с травмой/болезнью, временно или навсегда лишающей возможности пользоваться руками.
- Тем, кто хочет «пощупать» hands-free управление компьютером для исследований/прототипов.

После одноразовой настройки помощником приложение **запускается само** при включении Mac, само управляет курсором и голосом — без единого нажатия.

## Возможности

- 🎯 Трекинг лица в реальном времени (MediaPipe Tasks Vision, GPU/WASM).
- 🖱️ Перемещение системного курсора через `@nut-tree-fork/nut-js` (работает поверх любых приложений).
- 😉 Клик морганием (оба глаза 250–700 мс) на основе face blendshapes.
- ⏱️ Альтернатива — клик задержкой (dwell click).
- 🎙️ Голосовой ввод → печать в активное окно:
  - **Local Whisper (offline)** — whisper.cpp с моделью `large-v3`, Metal-ускорение на Apple Silicon. Лучшая точность RU/EN, без интернета.
  - **Web Speech API** (онлайн, встроен в Chromium);
  - **OpenAI Whisper** (если задан `OPENAI_API_KEY` в `.env`).
- 🔊 Непрерывный режим: VAD автоматически нарезает речь по паузам — говори без остановки.
- 🇷🇺 / 🇺🇸 / 🇰🇿 языки распознавания.

## Установка

```bash
cd /path/to/BeMyHands
npm install

# Один раз: установить whisper.cpp + скачать модель large-v3 (~3 ГБ)
brew install whisper-cpp
npm run setup

npm start
```

> При первом запуске macOS попросит доступ к **камере** и **микрофону**.

### Сменить модель Whisper

По умолчанию `large-v3` (топ по качеству, ~3 ГБ). Альтернативы — задать `WHISPER_MODEL` в `.env`:

| Модель             | Размер | Скорость на M2/M3 | Качество |
|--------------------|--------|--------------------|----------|
| `large-v3`         | 3.1 ГБ | ~1× реального времени | максимум |
| `large-v3-turbo`   | 1.6 ГБ | ~5× реального времени | очень высокое |
| `medium`           | 1.5 ГБ | ~10× | хорошо |
| `small`            | 488 МБ | ~20× | приемлемо |

```bash
echo 'WHISPER_MODEL=large-v3-turbo' >> .env
npm run setup     # скачает выбранную модель
```

## Разрешения macOS (обязательно)

Чтобы Electron мог управлять курсором и клавиатурой **за пределами** окна приложения, его нужно добавить в:

`System Settings → Privacy & Security → Accessibility`

В приложении кнопки в блоке «Разрешения macOS» откроют нужную панель.
**После добавления — перезапустите приложение.**

Если используете терминал (`npm start`) — в Accessibility надо добавить также `Terminal.app` или `iTerm.app`, либо упаковать приложение через `electron-builder` и запускать его как .app.

## Использование

### 🔧 Разовая настройка (помощник, человек с руками)

1. Запустить `npm start`.
2. Сесть перед камерой как обычно сидит пользователь, дождаться «Готово».
3. Нажать **🎯 Калибровать центр** (нейтральное положение головы).
4. Нажать **▶ Включить управление курсором**.
5. Подобрать **чувствительность** (X/Y) и **сглаживание** так, чтобы курсор уверенно доходил до углов экрана без перенапряжения шеи.
6. По очереди проверить жесты в таблице — попросить пользователя открыть рот, поднять брови, улыбнуться, закрыть один глаз. По live-индикаторам справа подкрутить пороги, если что-то срабатывает ложно или не срабатывает.
7. Включить голосовой ввод (🎙) с движком **Local Whisper (offline)** и галкой **Непрерывно**. Произнести «пауза», «продолжи», «клик» — убедиться, что команды распознаются (см. список ниже).
8. В блоке «Для безрукого использования» включить:
   - ✅ **Автозапуск при старте** — не надо ничего нажимать после запуска.
   - ✅ **Авто-пауза если лица нет 2 сек** — отвернулся → курсор замирает.
   - ✅ **Углы экрана** — экстренное управление приложением (см. ниже).
   - ✅ **Голосовые команды** — управление мышью словами.
9. Нажать **👤 Режим использования** — окно сворачивается в маленький виджет в правом верхнем углу. Все настройки сохранены, при следующем запуске всё сразу заработает.

### 👁️ Безрукое использование (после настройки)

После запуска (можно добавить приложение в **System Settings → General → Login Items** для автозапуска вместе с системой) приложение само:
- стартует управление курсором;
- запускает голосовой ввод в непрерывном режиме;
- показывает компактный виджет в углу со статусом.

**Голосовые команды** (распознаются перед печатью текста):

| Сказать | Действие |
|---------|----------|
| «пауза» / «стоп» | приостановить управление |
| «продолжи» / «старт» | возобновить |
| «калибровка» / «центр» | сбросить нейтральное положение головы |
| «клик» | левый клик |
| «правый клик» | правый клик |
| «двойной клик» | двойной клик |
| «вверх» / «вниз» | прокрутка |
| «ввод» / «энтер» | Enter |
| «удали» / «бэкспейс» | Backspace |
| «пробел» | Space |
| «настройки» / «покажи окно» | вернуть полное окно настроек |
| «выход» / «закрой» | закрыть приложение |

Всё что **не** команда — печатается как текст в активное окно.

**Углы экрана** (наведи курсор в угол на 1.2 секунды):

| Угол | Действие |
|------|----------|
| ↗ правый верхний | вернуть полное окно настроек (если что-то сломалось) |
| ↖ левый верхний | пауза / возобновить |
| ↘ правый нижний | 🛑 экстренная пауза (отпускает зажатую ЛКМ, выходит из всех режимов) |

**Жесты лицом:**

| Жест | Действие |
|------|----------|
| 👄 открыть рот | левый клик |
| 🤨 поднять брови | правый клик |
| 😊 улыбнуться | двойной клик |
| 👁️ закрыть **левый** глаз | удерживать ЛКМ (drag) |
| 👁️ закрыть **правый** глаз | режим прокрутки головой |

## OpenAI Whisper (опционально, облачный)

Если хочется облако вместо локального — переключите движок и пропишите ключ:

```bash
echo 'OPENAI_API_KEY=sk-...' > .env
npm start
```

## Структура

```
main.js        — Electron main: IPC, nut-js (мышь/клавиатура), Whisper proxy
preload.js     — безопасный мост в renderer
index.html     — UI
renderer.js    — MediaPipe + Web Speech + захват микрофона
styles.css     — оформление
```

## Известные ограничения

- nut-js на Apple Silicon собирается из исходников; нужен Xcode Command Line Tools (`xcode-select --install`).
- Web Speech API в Electron использует Google endpoint и иногда недоступен — тогда используйте Whisper.
- Нужен реальный физический экран (multi-monitor берёт `getPrimaryDisplay`).
